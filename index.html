Panduan & Tutorial Penggunaan Aplikasi

Selamat datang di Raport ATS Creator!
Aplikasi ini dirancang untuk memudahkan bapak/ibu guru dan wali kelas dalam mengonversi data nilai dari leger Excel secara otomatis menjadi lembaran Rapor Penilaian Asesmen Tengah Semester (ATS) yang siap dicetak maupun disimpan ke format PDF.
1

Unduh Format Template Excel

Jika belum memiliki format leger yang sesuai, klik tombol 📥 Template di bilah atas. Sistem akan mengunduh file template_leger_nilai.xlsx yang kolom-kolom mata pelajarannya sudah otomatis disinkronkan dengan pengaturan saat ini.

2

Pengisian Data Leger pada Excel

Buka file Excel dan isikan data nilai siswa:

  • Identitas Wali & Jurusan: Tuliskan nama wali kelas, NIP, Program Keahlian, dan Konsentrasi Keahlian pada baris 4 hingga 7.
  • Data Siswa: Isikan nomor urut, NIS/NISN, nama siswa, dan nilai pada kolom singkatan mata pelajaran yang bersangkutan.
  • Nilai Kosong / 0: Siswa yang tidak memiliki nilai atau bernilai 0 otomatis divalidasi dengan status "Tidak Mengikuti Ujian".
3

Impor File Excel ke Aplikasi

Klik tombol 📁 Impor Excel di bilah navigasi dan pilih file leger Anda. Aplikasi akan langsung memproses seluruh data siswa, memetakan nilai ke kelompok mata pelajaran umum & kejuruan, serta menghitung Jumlah Nilai dan Rata-Rata Nilai secara instan.

4

Kustomisasi Melalui Menu Pengaturan (⚙️ Pengaturan)

Gunakan menu pengaturan untuk menyesuaikan dokumen tanpa perlu mengubah kode:

  • Judul & Tahun Ajaran: Sesuaikan judul laporan dan tahun ajaran aktif.
  • Sekolah & Keahlian: Edit nama sekolah, alamat, program keahlian, dan konsentrasi keahlian.
  • Daftar Mata Pelajaran: Tambah mapel baru, ubah nama lengkap di rapor, atau hapus mapel yang tidak digunakan.
  • Kriteria KKM: Tentukan nilai batas kelulusan (KKM) serta redaksi keterangan kompetensi.
  • Tanda Tangan: Atur titimangsa tempat/tanggal, nama wali kelas, dan NIP.
  • Penyimpanan: Klik "Simpan ke Browser" agar seluruh setelan tersimpan di memori perangkat Anda.
5

Memilih Siswa & Mencetak (🖨️ Cetak)

Pilih opsi pada dropdown Siswa:

  • Pilih nama salah satu siswa untuk mencetak rapor lembar individu.
  • Pilih -- Cetak Semua Siswa -- untuk mencetak rapor satu kelas sekaligus (otomatis dipisah satu halaman per siswa).
  • Klik tombol 🖨️ Cetak untuk membuka dialog cetak browser.
💡 Tips Hasil Cetak / PDF Maksimal:
  • Ukuran Kertas: Pilih ukuran Folio / F4 (atau Legal / A4 sesuai kebutuhan).
  • Margin: Pilih Default atau None / Minimum.
  • Grafik Latar Belakang: Pastikan opsi "Background graphics" (Grafik latar belakang) dicentang agar border dan logo tercetak tajam.
